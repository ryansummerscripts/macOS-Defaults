<p align="center">
  Automatically set your default preferences for fresh macOS installs!
</p>

<p align="center">
  Dynamically sets compatible preferences based on macOS version, Architecture (ARM vs Intel) Machine Type (physical vs virtual) & Device Type (Laptop vs Desktop)
</p>

<p align="center">
  Disclaimer: These are my personal preferences.
  Be sure to look over the commented/uncommented commands to enable/disable what you need.
</p>

<p align="center">
  Alternatively, check out OneCommand to easily view and/or set these same preferences:
</p>

<p align="center">
  https://shop.ryansummer.com/p/onecommand/
</p>
